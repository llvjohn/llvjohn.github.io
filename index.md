# 🎨 EpiTrello - Manage Your Tasks Effortlessly

![Download EpiTrello](https://img.shields.io/badge/Download%20EpiTrello-Here-brightgreen)

## 📖 Overview

EpiTrello is a Trello-inspired Kanban web app designed to help you organize your tasks efficiently. With features like boards, columns, and drag-and-drop functionality, you can manage your projects with ease. The application uses secure authentication through Clerk and ensures safe database interactions with Supabase. Whether you're juggling personal tasks or professional projects, EpiTrello simplifies the process.

## 🚀 Getting Started

To get started with EpiTrello, follow the steps below. 

### System Requirements

EpiTrello is a web application, so you can access it from any modern web browser. Below are the recommended specifications:

- **Operating System:** Windows, macOS, or Linux
- **Web Browser:** The latest version of Chrome, Firefox, or Safari
- **Internet Connection:** Required for accessing the app

### 🎉 Features

- **Boards:** Create multiple boards for different projects.
- **Columns:** Organize tasks into columns to represent different stages.
- **Drag & Drop:** Easily rearrange tasks and columns using drag-and-drop functionality.
- **Secure Authentication:** Your data is safe with Clerk's authentication.
- **Real-time Updates:** Changes reflect immediately for all users.
